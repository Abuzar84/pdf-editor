# PDF Editor

Modern web-based PDF Editor built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, `pdf-lib` and `react-pdf`.

## Features (Planned)

- Upload PDF (drag & drop)
- View pages
- Add text annotations
- Highlight text
- Freehand drawing
- Delete / reorder pages
- Download edited PDF

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- pdf-lib
- react-pdf
- Zustand
- Framer Motion
- Lucide Icons
